# 码上起步 · 数据分析扩展版

面向编程新手的交互式学习网站。先学 Python，以小任务建立反馈，再选择数据分析路线或 Java 起步。数据分析的每个章节可分多次学习。

## 当前内容

- 12 个 Python 小任务：输出、变量、类型、输入、条件、循环、容器、函数、文件、异常、模块、待办清单。
- 3 个 Java 起步任务：首个程序、变量类型、方法与迷你学习计划计算器。
- 新增 16 个数据分析章节：NumPy 5 章、Pandas 7 章、Matplotlib 3 章、三库综合实战 1 章。共 66 张五步知识卡，进阶内容标注选学。
- 31 章每课 1 个基础练习、1 个综合练习、1 个选做挑战、2 道即时小测验，共 93 个代码任务与 62 道测验。新增部分为 48 个练习、32 道测验。
- 9 个工具救援专题，包含数据分析环境与 Seaborn / Plotly 本地运行示例。
- Python 真实运行、分级提示、练习检查、错题复习、术语、笔记、搜索、主题切换、手机适配。
- 本地学习记录保存与 JSON 导入导出。
- 按路线切换课程、跨章节搜索知识卡；知识卡实验台草稿独立保存。
- NumPy / Pandas / Matplotlib 按需加载；真实绘图预览与 PNG 下载；生成的 CSV / XLSX / JSON / NPY / TXT / PNG / PDF / SVG 文件下载。

## 使用边界

- 学习记录保存在当前浏览器；不同域名、本地预览与正式网站的数据相互独立，不自动跨设备同步。可导出再导入迁移。
- Python 首次运行会从 jsDelivr 加载固定版本 Pyodide 0.27.7，需要网络。执行超过 10 秒会停止，输出上限 50000 字符。
- Python 虚拟文件不是电脑上的真实文件，运行环境重置后可能消失。长期保存项目数据请在本地运行。
- 首次环境与扩展包加载允许最多 120 秒，执行仍限制 10 秒。沙盒固定 Pyodide 0.27.7，运行区显示实际库版本；本次浏览器实测 NumPy 2.0.2、Pandas 2.2.3、Matplotlib 3.8.4。
- 最多预览 4 张 Matplotlib 静态图；最多展示 10 个本次生成或修改的文件，每个 ≤3 MB。不支持个人文件上传，真实文件分析可按救援指南在本地执行。
- 沙盒未预装中文绘图字体，示例图使用英文；中文字体配置需对应环境中真实存在的字体。Seaborn / Plotly 提供本地示例，不提供在线交互图预览。
- Java 提供完整源码和 VS Code 指导，本版本不提供在线 Java 执行器。
- Python 练习检查适合个人学习，不是防作弊的考试系统；部分题目会提醒自行使用更多输入验证分支。
- 进度由学习者自评；首次和最近测验成绩分别保存。使用过提示或答案会记录相应帮助程度。
- 第一版未包含完整 Java 面向对象/集合/学生管理系统、Python 装饰器/生成器、账号和云同步，路线页已标明后续内容。

## 本地打开

在此文件所在文件夹打开终端，执行：

```powershell
# 启动本地静态服务
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

浏览器访问 http://127.0.0.1:4173 。不要双击 index.html 直接用 file:// 打开；模块和 Worker 需要 HTTP 服务。终端按 Ctrl+C 停止。

所有交付源码和文档保存在 D:\codex\agent学习\code-first。

## 开发结构

- dist/index.html：页面骨架与对话框。
- dist/styles.css：浅色/深色主题与响应式布局。
- dist/main.js：导航、学习状态、笔记、测验、搜索和运行交互。
- dist/curriculum.js：章节、练习、标准答案与测试规则。
- dist/data-curriculum.js：数据分析章节、五步知识卡、答案、判题与术语。
- dist/guides.js：环境与工具教程。
- dist/data-guides.js：数据分析安装、文件处理与可选绘图库指南。
- dist/science-worker.js：独立线程内的 Python 执行、按需加载、图表与文件输出。
- check-content.mjs：课程示例与参考答案的可重复验证。

采用浏览器原生模块组织第一版，不依赖前端构建步骤；后续可将相同课程数据迁移到 Vue 或 React。
